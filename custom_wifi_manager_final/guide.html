🔌 Before You Start

✅
Flash the firmware to your ESP, open Serial Monitor at 115200 baud, and watch the boot debug output. Then connect your PC/phone to the ESP's AP WiFi.
StepActionDetail
1Flash firmwareUpload custom_wifi_manager_final.ino via Arduino IDE
2Open Serial MonitorTools → Serial Monitor → 115200 baud → watch boot debug table
3Connect to ESP APWiFi name: PumpCtrl_XXXXXX — no password required
4Set Postman base URLAll requests use http://192.168.4.1
5Set Content-TypeFor all POST requests: Header Content-Type: application/json

🔄 Recommended Test Flow

1
GET /api/status Confirm the ESP is in AP mode and reachable at 192.168.4.1
2
GET /api/scan Get the list of nearby WiFi networks — note your home SSID
3
POST /api/setup Send ALL config in one call: WiFi credentials + all 7 device parameters
4
Wait ~5 seconds ESP saves to flash, closes AP, connects to your router. Check Serial Monitor.
5
Update Postman base URL to new ESP IP Find the new IP from Serial Monitor or your router's DHCP table
6
GET /api/config Verify all device parameters were saved correctly
7
POST /api/config Update device parameters without changing WiFi credentials

🚀 POST /api/setup — Full Setup (Most Important)

ENDPOINT 3 of 5
POST /api/setup Save ALL config + connect WiFi
FieldValue
MethodPOST
URLhttp://192.168.4.1/api/setup
HeaderContent-Type: application/json
Body → PostmanBody tab → raw → dropdown: JSON

Request Body (edit ssid & password)

{
  "ssid":          "YourWiFiName",     // your router SSID
  "password":      "YourWiFiPassword", // your router password
  "tankHeight":    100.0,              // cm — total tank height
  "sensorGap":     5.0,               // cm — sensor to tank top
  "pumpOnLevel":   20.0,              // % — pump ON threshold
  "pumpOffLevel":  90.0,              // % — pump OFF threshold
  "autoMode":      true,              // true=auto, false=manual
  "timerValue":    30.0,              // min — manual run time
  "unitCostPrice": 8.0                // BDT per kWh
}

Success Response 200 OK

{
  "status":  "success",
  "message": "All config saved! ESP connecting to WiFi..."
}
⚠️
After this response: The ESP will close the AP and connect to your router. Your Postman will lose connection to 192.168.4.1. Wait 5 seconds, then find the new ESP IP from your router or Serial Monitor. Update the base URL in Postman.

Validation Errors 400

{ "error": "Missing body" }
{ "error": "Invalid JSON" }

POST /api/config Update device params only
FieldValue
MethodPOST
URLhttp://192.168.4.1/api/config
HeaderContent-Type: application/json
✅ This endpoint only updates device parameters — it does NOT change WiFi credentials or disconnect the ESP.

Request Body

{
  "tankHeight":    120.0,  // can send partial — unset fields keep old value
  "sensorGap":     8.0,
  "pumpOnLevel":   15.0,
  "pumpOffLevel":  85.0,
  "autoMode":      false,
  "timerValue":    45.0,
  "unitCostPrice": 9.50
}

Response 200 OK

{
  "status":  "success",
  "message": "Device config updated!"
}

📦 Import Collection into Postman

Copy the JSON below → save as PumpController.postman_collection.json → In Postman: File → Import → Upload File. All 5 requests will be created automatically. 

{
  "info": {
    "name": "ESP Pump Controller",
    "_postman_id": "esp-pump-ctrl-v2",
    "schema": "https://schema.getpostman.com/json/collection/v2.1.0/collection.json"
  },
  "variable": [{ "key": "baseUrl", "value": "http://192.168.4.1" }],
  "item": [
    {
      "name": "1. GET Status",
      "request": { "method": "GET", "url": "{{baseUrl}}/api/status" }
    },
    {
      "name": "2. GET Scan WiFi",
      "request": { "method": "GET", "url": "{{baseUrl}}/api/scan" }
    },
    {
      "name": "3. POST Setup All (WiFi + Device)",
      "request": {
        "method": "POST",
        "url": "{{baseUrl}}/api/setup",
        "header": [{ "key": "Content-Type", "value": "application/json" }],
        "body": {
          "mode": "raw",
          "raw": "{\"ssid\":\"YourWiFi\",\"password\":\"YourPass\",\"tankHeight\":100,\"sensorGap\":5,\"pumpOnLevel\":20,\"pumpOffLevel\":90,\"autoMode\":true,\"timerValue\":30,\"unitCostPrice\":8}",
          "options": { "raw": { "language": "json" } }
        }
      }
    },
    {
      "name": "4. GET Device Config",
      "request": { "method": "GET", "url": "{{baseUrl}}/api/config" }
    },
    {
      "name": "5. POST Update Config Only",
      "request": {
        "method": "POST",
        "url": "{{baseUrl}}/api/config",
        "header": [{ "key": "Content-Type", "value": "application/json" }],
        "body": {
          "mode": "raw",
          "raw": "{\"tankHeight\":120,\"sensorGap\":8,\"pumpOnLevel\":15,\"pumpOffLevel\":85,\"autoMode\":false,\"timerValue\":45,\"unitCostPrice\":9.5}",
          "options": { "raw": { "language": "json" } }
